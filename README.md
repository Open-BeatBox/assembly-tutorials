# Open BeatBox Assembly Tutorials

> **This repository is archived.** The assembly tutorials and the Master BOM
> now live in the
> [Documentation repository](https://github.com/Open-BeatBox/Open-BeatBox_Documentation/tree/main/source/build/assembly-tutorials)
> (imported with this history) and are published in the
> [manual](https://open-beatbox.github.io/docs/manual/build/index.html).
> Please open issues and pull requests there.

Step-by-step assembly instructions for building the Open BeatBox enclosure and its hardware sub-modules.

## Tutorials

See the [tutorial index](tutorials_index.md) for links to all available assembly guides.

## Bill of materials

The complete bill of materials is available in two formats:

- [BOM.xlsx](BOM.xlsx) — editable spreadsheet
- [BOM.csv](BOM.csv) — portable CSV version

## Repository structure

```text
.
├── modules/              # Individual assembly tutorials
├── BOM.xlsx              # Editable bill of materials
├── BOM.csv               # CSV bill of materials
└── tutorials_index.md    # Index of all tutorials
```

## Contributing

Keep part identifiers consistent with the bill of materials. Place module-specific assembly instructions in the corresponding file under `modules/` and add new tutorials to the tutorial index.
