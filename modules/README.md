# Module packages

This folder contains the following module assembly guides:

- [`mod-bmt-assembly.md`](mod-bmt-assembly.md) — water bottle mount module (`MOD-BMT`).
- [`mod-fdr-aseembly.md`](mod-fdr-aseembly.md) — feeder module (`MOD-FDR`), including its housing, motor, rotor, PCBs, and cabling.
- [`mod-frm-assembly.md`](mod-frm-assembly.md) — enclosure frame module (`MOD-FRM`), including its walls, door, top panel, and submodule installation.
- [`mod-lgt.md`](mod-lgt.md) — light ring module (`MOD-LGT`), including its housing, PCB, cap, and diffuser.
- [`mod-pbg-assembly.md`](mod-pbg-assembly.md) — photobeam gate module (`MOD-PBG`), including the IR beam-break boards, controller, cabling, and covers.
- [`mod-scr-assembly.md`](mod-scr-assembly.md) — screen module (`MOD-SCR`), including the touchscreen, main PCB, IR boards, cabling, and housing.

Do not place authoritative module fabrication or troubleshooting information only in the system folder.
